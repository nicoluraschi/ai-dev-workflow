# Worked example: one change from spec to reviewed plan

One Tier B change, kept whole to show the process. It scopes Codex gate 6b to the PR in flight.
1. [Spec](2026-09-codex-6b-pr-scope.md): outcome from two measured false findings, scope, decisions, security requirements, acceptance criteria.
2. [Gate 1b review](reviews/2026-09-codex-6b-pr-scope-1b.md): Codex reviews the spec; 4 accepted, 0 rejected; round 2 finds no regressions.
3. [Plan](plans/2026-09-codex-6b-pr-scope.md): tasks mapped to the acceptance criteria.
4. [Gate 2b review](reviews/2026-09-codex-6b-pr-scope-2b.md): Codex reviews the plan; 5 accepted; round 2 catches 2 regressions the fixes introduced.
5. Spec §4 records each gate's outcome; the human closes what stays open.
Smaller specs followed the same spec → threat model → acceptance-criteria process.
